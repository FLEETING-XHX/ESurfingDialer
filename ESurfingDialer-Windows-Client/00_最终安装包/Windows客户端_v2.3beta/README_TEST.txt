ESurfingDialer Lite v2.3beta 测试说明

警告：这是预发布测试版。真实校园网认证、算法兼容、实际休眠/切网及长期运行仍待验证，不保证解决 v2.2 的认证失败。测试前保留原有可用的认证方式。

1. 安装
   运行 ESurfingDialer-Windows-v2.3beta-Setup.exe，按提示安装。

2. 首次使用
   打开 ESurfingDialer Lite，输入校园网账号和密码，点击“保存配置”，再点击“连接”。

3. 后台运行
   关闭窗口不会退出程序，只会隐藏到托盘。
   需要完全退出时，在窗口里点击“退出”，或右键托盘图标退出。

4. 开机自启
   勾选“开机自启”并保存配置后，下次登录 Windows 会自动启动。

5. 日志
   程序日志保存在：
   %LOCALAPPDATA%\ESurfingDialerLite\logs

6. 出问题时
   点击“导出日志包”，桌面会生成 ESurfingDialerLite-logs-时间.zip。
   把这个 zip 和问题截图发给维护者。

7. 热点测试
   先确认客户端显示已连接，再打开 Windows 移动热点。

8. 注意
   测试时建议先退出官方天翼校园客户端，避免两个客户端同时认证造成会话冲突。
