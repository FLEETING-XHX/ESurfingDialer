ESurfingDialer Lite v2.3beta.3 本地测试说明（2026-10-08）

本版本仅在本地打包，不推送、不发布。保留 beta2 的运行/账户/恢复修复，新增 10-08 门户兼容与 XML 诊断修复。
主要变化：兼容引号属性查询串中的裸 &，合并指向同一请求地址的重复 auth-url，继续拒绝冲突/无效配置；XML 失败日志区分解析器初始化、语法位置和固定错误类别。打包验证也增加就绪与进程清理门禁。
客户端为 .NET 10 WPF，包内仍包含 Java 21 和 Kotlin 认证核心；没有更换原生加解密算法。

2026-10-08认证通道修复版（UA2104）：旧Windows UA在初始化接口收到HTTP200但正文为空，导致ZSM_EMPTY。改用已验证的64位通道android11_64/2104，现有ARM64库保持；无账号测试身份已完成初始化和加密票据响应解析，核心327项认证/63项恢复通过。
此修复包与首次beta3的显示版本同为2.3beta.3/2.3.0.3，请以本说明的“UA2104”和安装器SHA256区分；导出日志的LOGIN_ATTEMPT应包含CCTP/android11_64/2104。真实账号登录与确认心跳仍需复测。

警告：这是预发布测试版。真实校园网认证、算法兼容、实际休眠/切网及长期运行仍待验证，不保证解决 v2.2 的认证失败。测试前保留原有可用的认证方式。

1. 安装
   先从窗口或托盘完全退出旧版，再运行 ESurfingDialer-Windows-v2.3beta.3-Setup.exe，按提示安装。
   旧版账户配置通常会保留；升级前可自行备份 %LOCALAPPDATA%\ESurfingDialerLite，备份中含加密账户信息，请妥善保管。

2. 首次使用
   打开 ESurfingDialer Lite，在账户管理中添加账号、密码和可选备注，点击“保存账户”。
   选择该账户，再点击主页“校园网”卡片开始连接；再次点击可停止。

3. 后台运行
   关闭窗口不会退出程序，只会隐藏到托盘。
   需要完全退出时，在窗口里点击“退出”，或右键托盘图标退出。

4. 开机自启
   开启“开机自启”后设置自动保存，下次登录当前 Windows 用户时自动启动。

5. 日志
   程序日志保存在：
   %LOCALAPPDATA%\ESurfingDialerLite\logs

6. 出问题时
   在设置页点击“导出日志”，选择 ZIP 保存位置。
   反馈时提供版本、发生时间、操作步骤、错误提示和检查过的脱敏日志。
   不公开账户配置、密码、ticket、密钥、原始 ZSM 或完整敏感 URL。

7. 热点测试
   先确认客户端显示已连接，再打开 Windows 移动热点。

8. 注意
   测试时建议先退出官方天翼校园客户端，避免两个客户端同时认证造成会话冲突。
   密码使用当前 Windows 用户的 DPAPI 加密；换用户或迁移配置后可能需要重新录入。
   本说明随 v2.3beta.3 新包交付；旧安装包仍保留各自原有代码与说明。
