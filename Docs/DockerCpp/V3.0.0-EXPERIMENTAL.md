## 离线使用

路由器需已安装Docker和Compose；完整包上传解压后，在目录内运行`sh install.sh`。脚本按CPU选镜像，使用本地归档导入，只创建容器，不启动或下载镜像。保留已有.env。

编辑.env填写账号密码，准备测试时将`NATIVE_EXPERIMENTAL`从默认0设为1；先停止旧认证服务，再执行`sh start.sh`。详细停止和回退方法见包内README.md。认证本身仍需访问校园网门户/服务器，离线安装不代表无网络也能完成认证。

Compose项目名`esurfing-native-v300`，容器名`ESurfingDialerNative-v3.0.0`，独立命名状态卷；默认restart:no、实验开关0、外置监控关闭。启动脚本拒绝与已知旧Kotlin/Native认证容器同时启动；不会替用户停止旧服务。
