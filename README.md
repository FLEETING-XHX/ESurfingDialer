# ESurfingDialer Windows Client

面向 Windows 桌面使用的 ESurfingDialer 客户端整理版。

本仓库基于原项目整理和打包：

- 原项目： [Itsuwarii/ESurfingDialer](https://github.com/Itsuwarii/ESurfingDialer)
- 项目入口： [FLEETING-XHX/ESurfingDialer](https://github.com/FLEETING-XHX/ESurfingDialer)

## 下载

- 最新安装包： [Release v1.01](https://github.com/FLEETING-XHX/ESurfingDialer-Windows-Client/releases/tag/v1.01)

## 适用场景

- Windows 电脑本机认证
- 不想使用软路由或 Docker 部署的用户
- 需要图形界面配置账号密码的用户

## 说明

本仓库用于维护 Windows 客户端源码、安装包构建和发布文件。Docker 软路由部署请使用：

- [FLEETING-XHX/ESurfingDialer-Docker](https://github.com/FLEETING-XHX/ESurfingDialer-Docker)
