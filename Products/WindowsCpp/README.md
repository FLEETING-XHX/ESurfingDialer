# Windows C++ / Qt Quick 测试客户端

**0.1.1 测试版状态**。Windows x64 已完成 6 组离线测试和本机安装、启动、卸载验证。真实校园网登录、持续心跳与长期稳定性仍待现场验收。


客户端采用 **C++ + Qt Quick（QML）**。桌面认证使用 2082 通道，账户密码由 Windows DPAPI 保护。2104 初始化探针独立构建，供开发诊断。

## 工程结构

- `qml/`：主页、日志、设置、账户面板、详细日志及通用组件。采用 Qt Quick 保留式渲染，不使用 GDI+ 手工重绘或子 HWND 混合绘制。
- `include/ClientServices.h`、`src/ClientServices.cpp`：与 UI 框架独立的 C++ 服务契约和内存预览适配器。
- `include/ClientBridge.h`、`src/ClientBridge.cpp`：QObject 适配层，向 QML 暴露只读快照和操作接口。轮询数据只有实际变化才发出通知，不按秒重建页面。
- `src/QuickMain.cpp`：Qt 应用入口、字体加载、QML 加载及冒烟验证。
- `assets/icons/`：由现有 WPF `PenIcons.xaml` 原字形导出的 SVG，保留 Lucide 许可；字体直接从同仓库 Windows 产品资源嵌入，不重复复制完整字体源码。
- `scripts/Build.ps1`、`scripts/Deploy.ps1`：Release 构建/定向测试，以及独立部署目录生成与 100 MiB 门禁。

## 已有页面与服务边界

已实现主页状态卡、流量显示区、浮动导航，日志列表、设置滚动页、账户增删改选和详细日志面板。以现有 `MainWindow.xaml`、`Theme.xaml`、`PenIcons.xaml` 为参考，复用 Noto Sans SC Regular/Bold 字体和图标轮廓。视觉完成度必须以同尺寸实机截图核对，不能仅凭编译或可点击宣称等价。

正常启动使用 `LocalClientServices`，在当前用户的 Windows 应用数据目录保存账户、选中项和设置。密码使用当前用户范围的 DPAPI 加密，账户摘要和日志不包含密码。配置文件使用原子替换和单实例锁，损坏或版本不支持时保留原文件。编辑同一账号时留空保留已保存密码。改动已有密码的账号名称（登录名）时需要重新输入密码。

认证操作通过 `IClientServices` 交给 C++ 后台线程。后台线程创建网络对象、解密所选账号的 DPAPI 数据并持有会话。通过首次心跳后才发布已连接状态。账户摘要、状态和日志只显示必要信息，密码只交给登录调用。QML/QString 内部仍可能存在临时副本。

重登时间字段沿用 WPF 校验：开始 00–23 点、结束 00–24 点，结束不得早于开始，起止相同表示定点执行。这只是预览设置校验，未执行重登计划。

## 硬性交付目标（2026-11-06 用户更新）

- 采用安装包安装，不要求单 EXE，允许安装目录包含 EXE、DLL、插件及资源。
- 每个交付架构的完整安装包不得超过 **100 MiB（104857600 字节）**。
- 安装后整个程序目录的文件逻辑大小合计不得超过 **100 MiB（104857600 字节）**，含主程序、认证核心、全部随附框架/编译器运行库、插件、QML、字体、图标、许可和卸载程序。
- 首次运行必须展开的程序依赖也计入；不得通过把必要文件移到目录外、依赖预装开发环境或启动后下载依赖来绕过体积目标。程序自行安装到其他位置的必要依赖亦须合并统计；操作系统原有组件不重复计算。
- 在功能、稳定性、视觉还原和兼容性不受影响的前提下越小越好。不能为缩包删除必要认证能力、TLS/证书验证、中文字符覆盖、所支持环境需要的渲染兼容组件或许可材料。
- 验收分别记录安装包字节数、安装完成及首次启动后的完整程序文件大小，并在干净目标系统核对依赖完整性。用户运行中产生的账户数据、日志和导出另行统计，日志需有容量上限，不能借用户数据目录藏匿程序依赖。

0.1.1 的两种测试包均通过本机 100 MiB 门禁，测量结果见下文。

## 构建与验证

需要 Windows、Visual Studio C++、Windows SDK、CMake，以及 Qt 6.8+ MSVC x64 SDK（Quick、QuickControls2、Svg、Network、Test）。

```powershell
./Products/WindowsCpp/scripts/Build.ps1 -QtRoot '你的 Qt SDK/msvc2022_64'
```

也可用 `QT_ROOT` 指定 SDK；本机默认探测仓库忽略目录 `artifacts/tools/Qt/6.10.0/msvc2022_64`。默认构建在 `build/qt`，配置为 Release；SDK、下载工具和验证产物都不进入源码交付。

测试包含 C++ 服务边界、Qt 桥接层静止轮询不发送重复通知、账户/错误边界，以及 offscreen QML 加载冒烟测试。它们不能代替实际 GPU、DPI、缩放、弹层和长期运行验证。

本机从构建目录启动时需将 Qt SDK 的 `bin` 加到进程 PATH；用户交付必须生成完整独立部署目录，不能依赖开发机 PATH。生成部署分析目录：

```powershell
./Products/WindowsCpp/scripts/Deploy.ps1 -QtRoot '你的 Qt SDK/msvc2022_64'
```

部署脚本拒绝覆盖已有目录，使用官方 `windeployqt` 扫描 QML/原生依赖，并统计全部文件逻辑大小。超过 100 MiB 会失败并保留现场分析，不自动删依赖。安装器还需单独统计自身及安装后卸载文件，不能把预览部署目录通过门禁当成最终安装包达标。

Qt 许可材料、所用版本的源码获取和重新链接等分发要求必须在正式交付前补齐核对。当前本机 SDK 与测试不构成公开发布。

## 2082 校园网测试版

`auth_session_2104` 实现门户发现、初始化、票据、登录、首次心跳确认、持续心跳和注销。参考 DockerCpp 的单会话所有权、有限次数重试和独立注销请求设计。已能访问互联网的网络单独报告，本进程通过首次心跳后才标记已认证。停止会取消正在进行的操作，有注销地址时通过独立传输尝试一次注销。心跳失败时只重试一次同一会话。

桌面连接入口使用原生 C++ 服务。Qt 提供界面、HTTP 和 XML，Windows DPAPI 保护已保存的密码，运行时依赖不包含 C#、.NET、Java 或旧 Windows 客户端。首次建立测试会话时，服务在独立的 `device-state.json` 中生成设备标识，后续连接沿用已保存的标识。门户解析目前接受 UTF-8 配置段，旧编码和只靠重定向参数的门户仍待兼容性验证。

构建命令会运行 `auth_session_offline` 和 `local_service_contract`。它们使用合成模块与账户覆盖保存、解密、确认在线、恢复、停止和注销。本机 HTTP 服务独立验证后台传输与限制行为。

桌面测试版默认使用 DockerCpp/OpenWrt 的 Android32/2082 通道。门户探测、初始化以及认证请求统一使用 2082 标识。Windows 原生加载器按已知代码指纹识别模块，需要能识别服务端当前返回的模块才会取票和读取密码。旧 Windows 2104 暂未启用，现有诊断工具继续用于采集 2104 样本。当前本机探测返回外网已通，真实登录、持续心跳和注销等现场结果尚未取得。

安装后，用 Windows 直连需要认证的校园网络，从开始菜单启动客户端。保存自己的校园账号和密码，点击「连接」，看到首次心跳确认后再验证外网是否可用。可以用「连接」按钮结束本次会话。若网络已经能上网，客户端会提示本进程没有建立认证会话。

构建 Release 后可生成独立的 x64 测试安装包。需要 Inno Setup 6 和应用本地 MSVC 运行库。输出目录须尚未存在。

```powershell
./Products/WindowsCpp/scripts/Build-TestInstaller.ps1 -QtRoot 'C:\Qt\6.12.0\msvc2022_64' -OutputDirectory './Products/WindowsCpp/dist/0.1.1-2082-local'
```

## 2104 初始化诊断

开发构建另有 `auth_bootstrap_probe.exe`，在能发现校园网门户的 Windows 环境下传入 `--output` 和一个尚不存在的本地模块文件路径。它使用随机测试 Client-ID，仅发送一次初始化请求，输出长度和 SHA-256。程序不读取账户，不发送账号、密码、取票请求、心跳或注销。输出文件供本地兼容性分析，探针不进入安装目标。运行时使用与桌面构建一致的 Qt SDK `bin` 路径。

```powershell
$env:Path = 'C:\Qt\6.12.0\msvc2022_64\bin;' + $env:Path
$sample = Join-Path $env:LOCALAPPDATA ("ESurfing-2104-{0}.bin" -f (Get-Date -Format 'yyyyMMdd-HHmmss'))
./Products/WindowsCpp/build/qt/Release/auth_bootstrap_probe.exe --output $sample
```
