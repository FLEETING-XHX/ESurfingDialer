# ESurfingDialer Windows v2.3beta 测试版

⚠️ **这是预发布测试版。** v2.2 的认证失败根因尚未通过真实校园网验证；本版本不保证解决所有学校的认证问题。测试前保留原有可用认证方式。Docker v1.3 不受本次更新影响。

## 本次更新

- 加强初始化脱敏诊断、原生句柄检查和门户 auth/ticket 入口发现。
- 严格校验认证响应、请求 XML 转义与读取上限；限制确定性失败重试，避免不断重启认证。
- 改进切网和缺 IP 门户恢复，保留并发恢复请求；休眠唤醒后主动重查网络。
- 停止连接时取消待恢复计时，退出时解除电源通知；原生会话安全释放并补充有界格式诊断。

## 下载与使用

前往 [v2.3beta Releases](https://github.com/FLEETING-XHX/ESurfingDialer/releases/tag/v2.3beta)，下载 `ESurfingDialer-Windows-v2.3beta-Setup.exe`。安装包包含 Windows x64 客户端、.NET 运行组件、Java 21 和认证核心，无需另外安装 Java/.NET。

1. 安装后输入校园网账号、密码，保存并连接；避免同时运行两个认证客户端。
2. 先验证登录和心跳，再测试切网、休眠恢复与长时间运行。
3. 失败时使用客户端的“导出日志包”，记录发生时间、错误提示和复现步骤；提交前检查日志脱敏，不公开密码、ticket、密钥或原始 ZSM。
