# Windows 六项离线修复记录（2026-09-30）

分支：`codex/windows-client-beta`。此前八项修复以 `3a3d3f1` 保存为基线。本轮依次修复并单独提交；本地通过不代表校园网登录或长期稳定性验收。

用户预计约七天后才可进行真实连接与使用测试。此次使用隔离目录、合成密码、健康快照和测试子进程，不修改原生加解密库、算法参数或 Docker。

## OFF-01：密码解密提示

- 原因：DPAPI 解密异常统一转为空字符串，连接和编辑界面无法区分未填密码、密文格式损坏与无法解密。
- 修改：保留原 DPAPI 的用户范围、附加数据与密文格式；增加结构化结果，连接前阻止无效密码启动，编辑界面提示重新输入且保留原配置。不能仅凭 DPAPI 异常区分损坏和其他 Windows 用户，因此提示明确保留两种可能。
- 回归：空值、坏 Base64、不可解密字节、原格式往返、实际 WPF 连接/编辑提示和配置字节保持。客户端离线回归 103 项通过（未加 --core），日志为工程 artifacts/offline-6-password.log。
- 范围：PasswordProtector、MainWindow 和客户端密码回归。

## OFF-02：连接状态

- 原因：恢复/暂停原因主要留在日志，主页与托盘统一成连接中或失败，手动停止缺少区别。
- 修改：统一中文状态及托盘/色彩映射，显示正在恢复、认证已暂停、恢复已暂停、用户已停止，并给出下一步。旧实例健康不能显示当前暂停，恢复上限即时更新提示，状态不变时也刷新连接按钮操作说明。
- 回归：112 项客户端离线检查通过，覆盖合成健康、旧实例、恢复/上限、停止与中文详情；实际查看 WPF 渲染 status-paused.png，新增状态未截断。日志为 artifacts/offline-6-status.log。

## OFF-03：账户保存、切换与删除失败

- 原因：原流程先停止当前核心，再改内存中的账户并写文件；保存失败时回读磁盘，连接已中断且原因提示不明确。
- 修改：复制候选配置，先写同目录临时文件、刷新并备份原配置，再停止必要的连接并最终替换。准备失败保留原账户/连接；替换失败保留原账户，明确提示连接已停止和手动重连。成功落盘才切换内存配置；串行化账户操作，失败清理临时密文。
- 回归：128 项客户端检查通过，包括写入/备份/替换注入，真实备份路径异常，保存/切换/删除的失败和成功路径，日志 artifacts/offline-6-account.log。首次测试暴露测试驱动缺少 WPF 同步上下文，已改为使用 DispatcherSynchronizationContext 与消息循环，未把此环境问题记为生产客户端缺陷。

## OFF-04：测试程序异常报告与清理

- 原因：测试入口没有统一失败边界；普通异常会直接交给系统，WPF 异步异常缺少统一失败结果，异常中断可能留下测试进程。
- 修改：入口统一返回非零失败码，将原始堆栈脱敏写入中文 stderr 与 failure.log；WPF Dispatcher 异常暂存后重新抛出并终止测试，不能记为通过。退出统一清理本轮拥有的子进程，依据 PID 与启动时间避免处理其他进程；失败与清理失败一起报告。
- 回归：136 项客户端离线检查通过；独立子进程主动制造普通/Dispatcher 异常，退出码为 1，原始堆栈保留，中文 stderr、token 脱敏和工作进程已退出均通过，日志 artifacts/offline-6-harness.log。
- 限制：仅处理测试程序失败边界，不捕获并继续运行状态未知的生产客户端；此前截图不能仅凭弹窗确定其唯一异常原因。
