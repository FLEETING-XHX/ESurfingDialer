# v2.4 发布说明

Windows 客户端与 Docker 软路由版从本次起统一使用 `v2.4`，在同一个 GitHub Release 交付。

| 下载文件 | 用途 |
| --- | --- |
| `ESurfingDialer-Windows-v2.4-Setup.exe` | Windows x64 安装器，内置 .NET 10、Java 21 和 Windows 认证核心 |
| `ESurfingDialer-Docker-v2.4.zip` | Linux amd64 离线镜像、安装/启动脚本与配置模板 |

下载见 [GitHub v2.4](https://github.com/FLEETING-XHX/ESurfingDialer/releases/tag/v2.4)。GitHub 自动提供的源码压缩包是源码，不是部署包。

## Windows 更新

汇入 beta2/beta3 的会话、门户、恢复与进程边界修复；Windows 初始化使用已验证的 `CCTP/android11_64/2104` 通道，保留原 ARM64 原生库。新版 UI 含内嵌中文字体、账户弹层、固定导航、渐隐滚动、充值/改密入口、后台提示，以及按显示器 DPI 和工作区适配的首开尺寸。修复连续拖动缩放回跳与账户圆角遮罩缺口。

统一发布入口组合核心回归、包内客户端回归、UI 检查、实际 EXE 就绪与清理、版本、运行时、来源和摘要检查。维护者可在 Windows 产品分支运行 `pwsh -NoProfile -File scripts/Build-Release.ps1 -Offline`，依赖本机已准备的 SDK/JDK 和缓存；任一门禁失败即停止交付，保留失败结果。

## Docker 更新

汇入 beta3 门户解析、会话恢复、健康监督、重认证计划与日志控制修复。新增配置末行换行保护、有效门户目标退避、特殊密码 CLI 保真、单调时钟心跳、日志进程故障监督与退出锁等待修复。

离线包使用校验过的 v1.3 amd64 Java 17 / Alpine 运行环境，叠加本轮 JAR 和运行脚本；安装默认仅创建独立的 `ESurfingDialer-v2.4` 容器，启动由用户显式执行。操作与配置迁移见[部署说明](../ESurfingDialer-Docker/02_使用教程/ESurfingDialer-Docker部署教程.md)。本次未新增 arm64 支持。

## 现场证据与剩余工作

Windows UA2104 修复版在 10-09 完成真实初始化、会话、票据、用户登录、首次确认心跳和外网访问；历史失败通道的唯一根因仍不据此重写。Docker beta3 在 10-08 完成一次真实登录、确认心跳和上网。上述是此前修复包的现场结果，不等于 v2.4 长期验收。

两端持续心跳、真实切网/休眠恢复、注销确认、72 小时与 7–14 天稳定性仍待补充。Windows 安装/升级/卸载与跨 DPI 实机矩阵、Docker 软路由重启与完整部署矩阵继续保留待办，见[修复总记录](修复与优化总记录.md)。
