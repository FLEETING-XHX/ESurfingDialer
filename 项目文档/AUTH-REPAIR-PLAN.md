## 当前交付与验证

- Windows 开发版本为 2.3；没有生成或发布正式安装包，也没有改变 Docker 认证实现。
- `scripts/Build-Core.ps1 -Offline -Regression`：构建认证核心并运行 21 项恢复检查、87 项认证检查。HTTP 用例均在本机模拟服务运行；原生句柄用可注入操作验证，不等于真实 ZSM 已被原生库接受。
- `dotnet run --project tests/ClientRegression -- <输出目录> --core`：最终 90 项客户端检查通过，含 WPF 渲染、当前进程失败标记、旧健康快照拒绝、健康文件导出脱敏、崩溃恢复、增强模式切换及停止取消延迟恢复。
- 修正了回归脚本对导航图标固定 DIP 容差的假设，容差改为当前 DPI 下一个物理像素；界面图标样式未变。
- 初始化响应最大 1 MiB；门户配置最大 128 KiB，门户 GET 最多三次请求，认证 POST 不跟随重定向。只在当前认证尝试中读取门户配置，不增加常态网络探测。
- ZSM 仅提取有界头部中的严格 UUID 候选。没有宣称完整解码或算法支持；未知布局继续交给原生提供者，原生拒绝与异常使用不同错误码。
- 同类确定性认证错误第三次失败后暂停；监督层不通过重启重置该预算，但仍恢复线程死亡、核心崩溃和过期健康状态。断开后重新连接可手动重试；用户 IP、AC IP 或门户主机/端口改变后也可重试。

第 5 项未完成：缺少故障校园网的受控 Algo-ID 与可验证测试向量，当前不能确定哪一个算法需要新增，更不能宣布 v2.1/v2.2 的真实认证故障已经完全解决。
